- **first-meeting-01 (۴۵ موردِ پرچم‌دار + ۲ پرامپتِ ارجاعی + ۲ نکتهٔ مبهم):** اشاره‌گر خط → خودِ واقعیت گفت‌وگو (کی چه گفت، خودِ نقل‌قول)؛ دو پرامپتِ «به پیش‌بینی برگرد» → «در مکالمه‌ای که دیدی…»؛ hint مبهمِ «به شمارهٔ نوبت‌ها فکر کن» و نقشهٔ L1→L12 → قوس روایی؛ تایپوهای はじめまて (×۲) و «はی» → はじめまして / はい.
