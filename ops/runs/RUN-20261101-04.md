## ۴. اقدامات انجام‌شده

۱) **پورت کامل توکن‌ها** (`tokens.css`، ۱۰۴→۱۶۱ خط): افزودن `--color-info/--scrim/--overlay-audio` · `--radius-full` · `--dur-shimmer/--dur-spin` + صفرشدن زیر reduced-motion (AC-907) · `--leading-fa/ja` · `--tracking-ja-heading` · hairline/shadow/z/touch/frame · نام‌های KB فونت (`--font-ja-ui/serif/ud`). استک فونت‌ها متغیر `*-loaded` (که next/font روی `<html>` می‌نویسد) را resolve می‌کنند — تک‌منبع همچنان tokens.css.
۲) **فونت سلف‌هاست**: بازتولید ساب‌ست‌ها با همان زنجیرهٔ `spikes/fonts-iran/reproduce.sh` (منابع پین‌شده) → ۷ فایل woff2 در `src/styles/woff2/` + ۳ فایل OFL: `vazirmatn-fd-{400,500,700}` (۹۵٫۲KB ≤ 100KB) · `zenkaku-starter-{R,M,B}` (۴۸۸KB ≤ 500KB) · `notoserif-vf` 200–900 (۱٫۱۵MB ≤ 1٫2MB) — جمع ۱٫۷۳MB ≤ هاردکپ ۲٫۳MB. اعتبارسنجی پوشش گلیف (نمونهٔ FA+JA): همهٔ ۷ فایل OK. `fonts.ts`: فقط Vazirmatn preload.
۳) **FuriganaText** طبق قرارداد spike M0-08 §۶: جزیرهٔ `direction:ltr + unicode-bidi:isolate + lang="ja"` · فقط group-ruby · `rt{user-select:none}` · line-height≥2 برای بلوک روبی‌دار (`.fg-block/:has(> .fg)`) · DSL ` base[reading]` + تابع `fromSurfaceReading` سازگار ساختاری با DialogueToken (بدون وابستگی ماژولی).
۴) **DirectionProvider** در `components/providers.tsx` (کلاینت) — الزامی برای رفتار Radix در RTL (spike M0-06).
۵) **React Compiler روشن**: `reactCompiler: true` در `next.config.ts` (توصیهٔ عددی اسپایک M0-05: ~۲۴× رندر مجدد سریع‌تر).
۶) **۹ کامپوننت shadcn** در `components/ui/` با API سازگار اما استایل‌شده با توکن‌های HANASO (نه متغیرهای پیش‌فرض shadcn) + سربرگ RTL-audit روی هر فایل: Button · Dialog · Sheet (sides منطقی start/end) · Tabs · Accordion · Tooltip · DropdownMenu (نشانگر زیرمنو ChevronLeft + ms-auto) · Command · Toast (sonner با dir=rtl). هرکدام: فاصله‌های logical، حالت‌های کامل، کف لمسی ۴۴px، فوکوس مرئی.
۷) **الگوهای دامنه** در `components/patterns/`: `JaBlock` · `FuriganaText` · `JapaneseSentence` (کارت جمله torinoko + ترجمهٔ پشت details/summary) · `AudioSentenceButton` (آیکونی با aria-label الزامی؛ آیکن‌های رسانه طبق قرارداد جهانی آینه نمی‌شوند).
۸) **دیکشنری تایپ‌دار** `src/messages/fa.ts` (ADR-013) — همهٔ رشته‌های UI کامپوننت‌های جدید از اینجا.
۹) **صفحهٔ مرجع رندر** `/poc/ui` (AC-2): پاراگراف ترکیبی FA+روبی+JA + کارت جمله + دکمهٔ صوت + هر ۹ کامپوننت در RTL.
۱۰) **دروازه‌های جدید**: `lint:css` (stylelint + stylelint-use-logical؛ AC-1) و `check:fonts` (بودجهٔ §۶-۲ + الزام OFL) — هر دو در `scripts/verify-foundation.sh` (۷→۹ گیت).
