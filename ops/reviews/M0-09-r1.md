## Verified-good

- **Token port fidelity (DD-067):** every color, type, leading/tracking, furigana, radius, shadow, scrim/overlay, motion, z and measure value verified 1:1 across KB file → app `tokens.css` → **built CSS** (including minified forms: `#2b2a2866` = scrim 0.40, `#f7f3e9db` = overlay 0.86, `1.4s` = 1400ms, `max(.5em,12px)`). `--info` literal `#1d4e70` = `var(--ai)` value, documented. Radius overrides (`md:8px`, `lg:12px`) correctly displace Tailwind defaults; `rounded-full` resolves `var(--radius-full)`. The `:root` duplicates for tree-shaken speaker colors are documented and value-identical.
- **Font wiring:** the `--font-*-loaded` pattern is sound — next/font writes the variables via SSR'd class on `<html>`, `@theme` emits `--font-fa` etc. to `:root` (verified in build), and the `var(--font-fa-loaded, 'Vazirmatn')` fallback reproduces the exact KB chain if the webfont layer is absent. Deviation from spike §6-1 variable names is documented in the run record with a valid rationale (masked family + tokens.css single source). `preload: true` only on Vazirmatn; `display: swap` everywhere; `--font-ja-ud` correctly deferred per §6-2 budget.
- **Font files & budget:** all 7 woff2 byte-sizes match the spike reproduction exactly (95,220 / 487,848 / 1,146,896 B; total 1,729,964 B ≤ 2.3MB); 3 OFL files present and non-empty; gate script is fail-closed (`set -euo pipefail`, `stat` errors on missing globs).
- **FuriganaText vs spike M0-08 §6:** props shape + DSL extension, island via `.fg` CSS (`direction:ltr` + `unicode-bidi:isolate`) + `lang="ja"`, group-ruby only, `rt` 50%/12px floor + `user-select:none`, `.fg-block, :has(> .fg) { line-height: 2 }`, `furiganaPlainText` built from bases only, `fromSurfaceReading` structurally compatible without module imports. DSL parser edge cases (escaped brackets, unclosed `[`, no-base, multi-ruby) all handled and genuinely tested.
- **Module boundaries:** zero imports from `src/modules/*` in `components/ui` + `components/patterns` (grep-verified); `fa.ts` is a typed dictionary matching ADR-013's shape; `layout.tsx` wires variables + `lang="fa" dir="rtl"` + `Providers` + `Toaster` correctly.
- **Logical utilities / RTL:** no physical `left/right` in any component (stylelint gate + tokens-gate test + manual read); Sheet sides are `start/end`; DropdownMenu uses `ms-auto` + mirrored `ChevronLeft` per spike M0-06; Dialog centered with `inset-x-0 + mx-auto` (no `translate-x` RTL trap); `text-align: start` inside the LTR island is value-equivalent to KB's `left` and documented.
- **Gates:** `verify-foundation.sh` runs 9 gates in a sane order (install→format→lint→stylelint→tsc→vitest→build→fonts→smoke→secrets); stylelint-use-logical 2.1.3 is correctly wired; React Compiler `true` matches spike M0-05's recommendation (plugin pinned, build green).
- **Honesty of the run record:** WebKit sandbox limitation and the standalone `.next/static` quirk were recorded rather than hidden; the probe artifacts (`browsers-probe.json` + 2 screenshots) are committed and their measurements match the code.

## Verdict

**NEEDS-FIX** — two S1 blockers must be fixed before merge:

1. **F1** — `z-modal`/`z-drawer`/`z-toast` utilities generate no CSS; the KB layering contract (and three audit-header claims) are dead code.
2. **F2** — unconfigured `tailwind-merge` silently deletes custom font-size utilities on 10+ surfaces (DialogTitle/SheetTitle lose `text-h3`, menus/tooltips/summaries lose `text-small`), violating the locked DD-067 type scale.

Both are small, localized fixes (a `@utility` block / `z-[var()]` + one `extendTailwindMerge` config), but they invalidate "token-only styling" and "z-index = token" claims as shipped. S2 items (F3–F8) are strongly recommended in the same PR; S3 items can be follow-up issues.
