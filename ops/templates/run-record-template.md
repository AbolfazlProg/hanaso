# قالب رکورد اجرا (run-record) — HANASO

> هر اجرای Agent در هر نقش = یک رکورد **append-only** در `ops/runs/RUN-YYYYMMDD-NN.md`.

## فیلدها

1. **شناسه:** RUN · تسک · فاز · نقش Agent (Orchestrator/Builder/Reviewer/Remediation/Integration) · زمان شروع/پایان (Asia/Tehran) · Agent/مدل اجراکننده · Commit SHA (یا «تا_commit»)
2. **هدف و محدوده** (۲-۳ خط)
3. **اسناد خوانده‌شده**
4. **Skillهای استفاده‌شده + نحوه** (جدول طبق `docs/engineering/skills/AGENT_SKILL_USAGE_POLICY.md` §۵ — نام + اثر واقعی؛ حذف این بخش = نقض سیاست)
5. **اقدامات انجام‌شده** (به ترتیب)
6. **فایل‌های تغییرکرده**
7. **تست‌های اجراشده + نتایج واقعی** (خروجی فرمان‌ها)
8. **نقص‌های یافته‌شده + شدت**
9. **بازبینی/بازبین**
10. **وضعیت تسک پس از اجرا** (از ۱۰ وضعیت)
11. **مانع‌ها** (لینک BLOCKER)
12. **گام بعدی/مسئول**
13. **آخرین به‌روزرسانی** + **اصلاحیه‌ها (Corrigenda — append-only)**
