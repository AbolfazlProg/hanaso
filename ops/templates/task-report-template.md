# قالب گزارش تسک (task-report) — HANASO

> Builder پس از خودراستی‌آزمایی و پیش از تحویل به بازبین مستقل (مرحلهٔ ۴ چرخه).

## بخش‌ها

1. **خلاصه** (۱-۲ خط + ارجاع FEAT/AC/Issue)
2. **Skillهای استفاده‌شده** (جدول: Skill | چگونه استفاده شد — یا دلیل ثبت‌شدهٔ Skip؛ ردیف ماتریس انتخاب: `docs/engineering/skills/SKILL_SELECTION_MATRIX.md` — داخلی SKL-xxx + خارجی EXT-xxx)
3. **اسناد خوانده‌شده** (مسیرها)
4. **شواهد دروازه‌ها** (فرمان → خروجی واقعی؛ خروجی بریده/ویرایش‌شده شاهد نیست؛ گیت اجراننشده = دلیل صریح)
5. **فایل‌های تغییرکرده** (مسیر + خطوط افزوده/حذف + نقش)
6. **تصمیم‌های اتخاذشده** (هرکدام با ارجاع به Spec/ADR/DD — یا پرچم «نیازمند ADR/OTD جدید»)
7. **نتیجهٔ خودبازبینی** (یافته‌ها یا «—»)
8. **اقلام باز / تحویل به بازبین**
