# عملیات Agent (ops/) — HANASO

سیستم عامل Agentهای توسعه (طبق KB ADR-015 — repo-agnostic؛ اینجا نسخهٔ ریپوی محصول):

| فایل/پوشه          | نقش                                                                                |
| ------------------ | ---------------------------------------------------------------------------------- |
| `TASK_REGISTRY.md` | تنها منبع وضعیت تسک‌ها (۱۰ وضعیت) — هم‌روز با GitHub Issues                        |
| `PHASE_STATUS.md`  | وضعیت فازها + چک‌لیست ۹بندی عبور از فاز                                            |
| `BLOCKERS.md`      | مانع‌های اجرایی (`BLOCKER-F<nn>`) — گیت‌های تصمیم در KB می‌مانند                   |
| `NEXT_ACTIONS.md`  | صف اقدام‌ها با مسئول/پیش‌نیاز                                                      |
| `AGENT_RUN_LOG.md` | ردیف هر اجرا + لینک رکورد کامل                                                     |
| `runs/RUN-*.md`    | رکوردهای اجرا — **append-only** (اصلاح = ضمیمهٔ مؤرخ)                              |
| `reviews/*.md`     | گزارش‌های بازبینی مستقل (S0..S3)                                                   |
| `templates/`       | پنج قالب استاندارد: task-spec · task-report · review-report · run-record · handoff |

قواعد: هر اجرا در ۴ نقطه ثبت می‌شود (شروع/milestone/مانع/پایان)؛ سازنده هرگز بازبین مستقل کار خودش نیست؛
هیچ ادعای انجام/push/deploy بدون خروجی واقعی فرمان معتبر نیست؛ اگر ناممکن است، مانع دقیق ثبت می‌شود.
