## ۱) خلاصهٔ یک‌پاراگرافی

روش تدریس قواعد پایهٔ ژاپنی در ۸ ایستگاه فصل کانا از «یک کارت قاعدهٔ متراکم + گرید مثال + بلوک‌های آزمون‌گونهٔ ۳-۵تایی» به **دک‌های اسلایدی ۱۲-۱۵ مرحله‌ای** بازطراحی شد: بازخوانی پیش‌نیاز (بازیابی فعال) ← مشاهدهٔ هدایت‌شدهٔ واژهٔ واقعی با بخش قاعده‌دار برجسته ← **مقایسهٔ زندهٔ جفت با پخش پشت‌سرهم + شمارندهٔ ضرب (beat dots)** ← توضیح تک‌مفهومی ← پیش‌بینی بدون نمره (pretesting) ← تمرین هدایت‌شدهٔ ۱-۲تایی ← کاربرد ۱-۲ واژه ← بازیابی مستقل ← کارت مرجع (جدول بعد از تجربه) ← ارزیابی با واژهٔ تازه ← جمع‌بندی. قانون طلایی («هیچ سؤال/مثالی به دانش آموزش‌نداده وابسته نباشد») **مکانیکی** شد: ۶ گیت اعتبارسنجی جدید همهٔ سطوح متنی (جدول‌ها، گزینه‌ها، chips، اسلایدها) را می‌سنجند و ۱۰۲ تخلف واقعی موجود در محتوای قبلی پیدا و رفع شد.
