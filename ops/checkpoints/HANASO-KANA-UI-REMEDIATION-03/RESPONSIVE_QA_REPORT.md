# RESPONSIVE QA REPORT — HANASO-KANA-UI-REMEDIATION-03 (§4)

> جاروی ریسپانسیو کل مسیر یادگیری فصل ۱ کانا — با probe خودکار (`scripts/responsive_probe.js`) + تعامل دستی مرورگر.

## روش

- ابزار: agent-browser (headless Chromium واقعی) + probe JS که در صفحهٔ زنده اجرا می‌شود.
- probe می‌سنجد: سرریز افقی (`scrollWidth - innerWidth`)، کنترل‌های کلیپ‌شده (فراتر از لبه‌ها)، لمس‌هدف‌های <44px (فقط button/role=button/radio/checkbox مرئی)، متن <12px، runهای کانای بدون isolation bidi.
- صفحات: مسیر یادگیری (journey)، ایستگاه تدریس+نوشتن (h1)، ایستگاه practice مستقل (p3)، هاب تمرین (practice).
- عرض‌ها: 360 / 390 / 430 / 768 / 1024 / 1440.
