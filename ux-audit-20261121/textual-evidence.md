# شاهدهای متنی ثبت‌شده در طول ممیزی (کپی عینی از innerText/الگوها)

## 1. گزینهٔ تکراری در کوئیز واژگان (stn-fm01-02-vocab، مرحلهٔ ۱۱/۱۲)
innerText زمان پاسخ:
```
۱۱ / ۱۲   ۱ / ۱   واژگان
کدام واژه در نوبت ۸ آمده است؟
イランじん
イランじん
ちゅうごくじん
かんこくじん
درست!
```
دو گزینهٔ اول دقیقاً یکسان هستند (イランじん دو بار).

## 2. کاراکتر فارسی ک (U+06A9) به‌جای く (U+304F)
بازخورد نادرست کوئیز ملیت (stn-fm01-02-vocab):
```
نادرست
ملیتی که شنیدی «ژاپنی» بود — にほん را با ちゅうごک قاطی نکن.
```
بررسی کدپوینت رشتهٔ «ちゅうごک»: ち(0x3061) ゅ(0x3085) う(0x3046) ご(0x3054) ک(0x6A9 — KEHEH فارسی، نه く U+304F)

## 3. کارت‌های خالی در /review (۱۷ کارتfm01)
```
۱۷ کارت برای مرور — ۱ / ۱۷
این کارت در محتوای فعلی یافت نشد — می‌توانی رتبه‌اش را ثبت کنی یا رد کنی.
```
کارت‌های ۱ تا ۶ بررسی شدند — همه همین پیام.
API: /api/review/queue → {"engine":"FSRS-6","status":"integrated","dueCount":17}
نمونهٔ کارت: {"itemId":"s-fm01-nihonjin","kind":"s","wave":1,"contextLineId":"s-first-meeting-01-l3"}

## 4. راهنمای غلط جهت ضربهٔ ۱ あ (stn-kana-h1)
متن آموزش (مرحلهٔ ۱/۱۲):
```
ضربهٔ 1 از 3 — از بالا-چپ شروع کن / به سمت بالا بکش / تقریباً مستقیم است
```
ویجت «ترتیب ضربه‌ها»:
```
۱ — از بالا-چپ — به سمت بالا
۲ — از بالا — به سمت پایین
۳ — از وسطِ نویسه — به سمت پایین
```
انیمیشن SVG ضربهٔ ۱ را افقی چپ→راست می‌کشد (فریم‌های 07c)؛ اعتبارسنج هم کشیدن افقی را پذیرفت (۱/۳→۲/۳).

## 5. نشت شناسهٔ داخلی در درفت n5l01-01 (مرحلهٔ ۱/۱۰)
```
اتصال به مکالمه: s-first-meeting-01-l1
```

## 6. ادعای کارت بدون افکت (wrap-up stn-kana-h0)
```
کارت‌های مرور (FSRS) این کاناها در صف مرور ثبت شدند — مرورشان را از صفحهٔ «مرور» در خانه انجام بده.
```
بلافاصله: /api/review/queue → dueCount:0؛ صفحهٔ خانه لینکی به مرور ندارد.

## 7. قالب بازخورد خراب «درست! بود»
کوئیز شنیداری واژگان: «درست! بود — به سؤال بعدی می‌رویم…» (الگوی {verdict} بود)

## 8. لو رفتن پاسخ قبل از تلاش مجدد
```
نادرست — ملیتی که شنیدی «ژاپنی» بود ...
دوباره تلاش کن
```
و در کوئیز شنیداری درفت: پس از نادرست، گزینهٔ درست (ミキ) در پایین نمایش داده شد.

## 9. گزینهٔ درست کوئیز درفت (کلید ۴)
سؤال: «در کل مکالمه چند نفر خودشان را معرفی می‌کنند؟» → کلید درفت «چهار نفر».
طبق ترانکریپت مکالمه، معرفیِ خودی ۳ مورد است (یامادا l3، سورا l4، کیم l12)؛ علی توسط یامادا معرفی می‌شود نه خودش.

## 10. CTA «ادامهٔ یادگیری» روی ایستگاه کامل‌شده
بعد از تکمیل ۳ ایستگاه ch2: «ادامهٔ یادگیری — اولین مواجهه — کل مکالمه» (ایستگاه ۱) + نشان «ایستگاه فعلی» روی ایستگاه ۱.
