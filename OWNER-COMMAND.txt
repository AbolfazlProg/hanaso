WHAT THIS IS
  The single copy-paste command that installs or updates HANASO on the VPS
  (run as root). No GitHub Token, no password, no Deploy Key — the repository
  is public and everything arrives over anonymous HTTPS.

WHAT'S NEW IN v10 (HANASO-17)
  1. The release bundles EVERYTHING from 1.0.0-hanaso16-r01 (the progressive
     learning journey, live in production since 2026-11-11) PLUS the new
     unified daily experience: / is now a real LEARNER HOME — a quiet,
     professional dashboard that answers "what do I do today?" with ONE
     primary CTA resolved from real progress (start / continue / restart-after-
     absence / next lesson / mastery gate), a secondary "next new lesson" card,
     an honest review line (NO fake counts — the FSRS engine is honestly not
     integrated yet), and a compact link to the learning map.
  2. MAIN NAVIGATION: desktop top bar + mobile bottom tab bar (خانه · مسیر
     یادگیری) on top-level pages only — lessons/assessments stay immersive.
  3. COMPLETED LESSONS ARE ALWAYS REPLAYABLE: clicking a completed row in the
     map opens the lesson FROM THE TOP in review mode (?mode=review) — no more
     "completed" wall. Nothing re-registers: no duplicate completion, no
     duplicate rewards, mastery/FSRS untouched.
  4. LESSON END, FIXED: exactly ONE CTA — «پایان درس و بازگشت به مسیر» —
     back to the SAME map section (?s=). The next lesson is shown as a text
     line, never auto-opened.
  5. TIME-BOXED RESUME: a half-finished lesson's resume pointer expires after
     7 days without meaningful activity (a plain refresh does NOT extend it);
     the CTA becomes «شروع دوبارهٔ درس» with a neutral notice. Only the walk
     POSITION expires — completed lessons, history, mastery, FSRS data are
     never touched. One additive migration (0003: station_progress.
     last_activity_at); no seed change; full backward compatibility.

THE COMMAND — copy this block and paste it whole into the VPS shell as root
(it is a multi-line heredoc — safe against SSH paste line-breaking, unlike the
old 2.7KB single-line bash -c):

bash <<'HANASO-V10'
set -euo pipefail
H=AbolfazlProg/hanaso
P=infra/deploy/bootstrap-hanaso.sh
R=aaa5fea45f43175e4de9772bce6b354c0e0126d2
W=03ee6e740db0860dd1149ca689ea2d84b9634becfc8f6a8e30632bb660770035
D=3f41f6ee510e28914934ddc83375a0e1d49405a3
T=/tmp/hanaso-bootstrap-v10.sh

echo "[hanaso] 1/3  download bootstrap (ref $R) via api.github.com"
if ! curl -fsSL --connect-timeout 10 --max-time 60 \
        -H "Accept: application/vnd.github.raw" \
        "https://api.github.com/repos/$H/contents/$P?ref=$R" -o "$T"; then
  echo "[hanaso]    api.github.com failed (real curl error above) — trying codeload.github.com"
  X="$(mktemp -d /tmp/hanaso-dl.XXXXXX)"
  curl -fsSL --connect-timeout 10 --max-time 300 \
       "https://codeload.github.com/$H/tar.gz/$R" -o "$X/src.tgz"
  tar -xzf "$X/src.tgz" -C "$X" "hanaso-$R/$P"
  mv "$X/hanaso-$R/$P" "$T"
  rm -rf "$X"
fi

echo "[hanaso] 2/3  verify SHA-256 — nothing runs unless it matches"
echo "$W  $T" | sha256sum -c -

echo "[hanaso] 3/3  start installer — deploy target: $D (1.0.0-hanaso17-r01)"
HANASO_DEPLOY_SHA="$R" HANASO_TARGET_SHA="$D" bash "$T"
HANASO-V10
