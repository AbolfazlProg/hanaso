DOWNLOAD PATHS (tried in this order — the design follows the owner's live VPS
evidence of 2026-11-08: github.com git OK · api.github.com 200 · codeload 200 ·
raw 200 only on 185.199.108.133, SSL timeouts on the other three raw IPs):
  1/2  api.github.com       contents API at the pinned tooling commit (tiny
                            payload; an anonymous rate-limit 403 just falls
                            through)
  2/2  codeload.github.com  tarball of the pinned tooling commit, single-file
                            extract
  The bootstrap's REAL SHA-256 is checked against the pin above BEFORE
  anything is executed — a corrupted or proxy-mangled download can never run.
  curl errors are printed verbatim; nothing is hidden.

THE COMMAND — copy this block and paste it whole into the VPS shell as root
(it is a multi-line heredoc — safe against SSH paste line-breaking, unlike the
old 2.7KB single-line bash -c; paste it INCLUDING the closing HANASO-V11 line):

bash -s -- <<'HANASO-V11'
set -euo pipefail
H=AbolfazlProg/hanaso
P=infra/deploy/bootstrap-hanaso.sh
R=TOOLING_SHA_PLACEHOLDER_0000000000000000000000000000000000000000
W=03ee6e740db0860dd1149ca689ea2d84b9634becfc8f6a8e30632bb660770035
D=2574788c36521cec6ac0673488b769e77a8ab982
T=/tmp/hanaso-bootstrap-v11.sh

echo "[hanaso] 1/3  download bootstrap (ref $R) via api.github.com"
GOT=""
if curl -fsSL --connect-timeout 10 --max-time 60 \
        -H "Accept: application/vnd.github.raw" \
        "https://api.github.com/repos/$H/contents/$P?ref=$R" -o "$T"; then
  GOT="api.github.com"
else
  echo "[hanaso]    api.github.com failed (real curl error above) — trying codeload.github.com"
  X="$(mktemp -d /tmp/hanaso-dl.XXXXXX)"
  if curl -fsSL --connect-timeout 10 --max-time 300 \
       "https://codeload.github.com/$H/tar.gz/$R" -o "$X/src.tgz"; then
    if ! tar -xzf "$X/src.tgz" -C "$X" "hanaso-$R/$P"; then
      echo "ERROR: codeload tarball fetched but extraction FAILED (tar error above) — NOTHING was executed or changed" >&2
      exit 1
    fi
    mv "$X/hanaso-$R/$P" "$T"
    rm -rf "$X"
    GOT="codeload.github.com"
  else
    echo "ERROR: ALL bootstrap download paths failed (api.github.com and codeload.github.com) — the real curl errors are printed above; NOTHING was executed or changed" >&2
    exit 1
  fi
fi
echo "[hanaso]    bootstrap delivered via ${GOT}"

echo "[hanaso] 2/3  verify SHA-256 — nothing runs unless it matches"
echo "$W  $T" | sha256sum -c -

echo "[hanaso] 3/3  start installer — deploy target: $D (1.0.0-hanaso20-r01)"
HANASO_DEPLOY_SHA="$R" HANASO_TARGET_SHA="$D" bash "$T" "$@"
HANASO-V11
