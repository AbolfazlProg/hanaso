# ADR-001 — Repository Identity: `hanaso`

**TL;DR (فارسی):** ریپوی محصول `hanaso` (private) با دامنهٔ هدف `hanaso.ir` و Preview روی `preview.hanaso.ir` است؛ نام کاری قدیمی `japanese-learning-app` منسوخ می‌شود و KB مرجع Spec باقی می‌ماند.

- **مسئله:** نام و هویت ریپوی محصول (OQ-002 در KB باز بود) و تفکیک آن از مخزن دانش.
- **گزینه‌ها:** (۱) `hanaso` طبق دستور مالک ۲۰۲۶-۱۱-۰۱ · (۲) نام قدیمی `japanese-learning-app` · (۳) نام جدید دیگر.
- **شواهد:** پیام مأموریت مالک ۲۰۲۶-۱۱-۰۱: «نام محصول کاری: HANASO · دامنهٔ هدف: hanaso.ir · Repository پیشنهادی: hanaso» — تصمیم صریح مالک.
- **مقایسه:** گزینهٔ ۲ با دستور مالک در تعارض؛ گزینهٔ ۳ بدون دلیل. بررسی دسترسی: `GET /repos/AbolfazlProg/hanaso` → 404 (نام آزاد بود — پیش از ایجاد).
- **تصمیم:** ریپوی private `AbolfazlProg/hanaso`، شاخهٔ پیش‌فرض `main`، زبان مدیریتی فارسی/فنی دوزبانه؛ KB همچنان مرجع مستقل Spec (DD-026)؛ ثبت رسمی پاسخ OQ-002 در KB از مسیر spec-gap (ایssue باز شد).
- **مزایا:** کوتاه/قابل‌تلفظ · هم‌نام برند و دامنه · جدایی کامل Spec از کد. **معایب:** ارجاع‌های قدیمی به نام قبلی در اسناد KB (پذیرفته — با اصلاح تدریجی از مسیر KB).
- **هزینهٔ تغییر آینده:** تغییر نام = rename GitHub + به‌روزرسانی remotes/CI/مستندات (متوسط)؛ تغییر دامنه = Caddy + DNS + انتقال TLS.
- **ریسک‌ها:** DNS `hanaso.ir` از محیط Agent resolve نشد (BLOCKER-F04) — مالکیت/رکوردها باید توسط مالک تأیید شود؛ تا تأیید، Preview می‌تواند با IP:port موقت کار کند.
- **وضعیت تأیید:** `CONFIRMED` توسط مالک (پیام مأموریت) — ثبت در رجیستری KB در جریان.
