# چک‌لیست اقدامات مالک (VPS-OWNER-CHECKLIST) — HANASO

> این اقدامات **فقط از سمت مالک** قابل انجام‌اند (دسترسی/مالکیت/پرداخت). پس از هر اقدام، Issue متناظر در ریپو را با ذکر نتیجه ببندید.

## ۱. بیلینگ GitHub (بحرانی — BLOCKER-F03)

- [ ] Settings → **Billing & plans** → روش پرداخت معتبر + سقف هزینه را اصلاح کنید.
- [ ] یکی از workflowهای ریپوی `hanaso` را **Re-run** کنید و سبزی jobs را ببینید.
- [ ] خبر دهید تا required status checks روی `main` فعال شود (BLOCKER-F05).

## ۲. سرور (BLOCKER-F02 — طبق ADR-010 KB)

- [ ] یک VPS **اروپایی** تهیه کنید (۲vCPU/4GB کف M0). **Hetzner ممنوع** (بند تحریم ToS — TRK-010). گزینه‌ها: OVH (بند منفی یافت‌نشده — بازراستی‌آزمایی نشده)، Contabo، …
- [ ] Docker + Compose نصب (`curl -fsSL https://get.docker.com | sh`).
- [ ] دسترسی SSH برای Agent فراهم کنید (کلید اختصاصی، غیر-root، فایروال 80/443/SSH).
- [ ] خروجی `docker ps` فعلی را برای ما ذخیره کنید (مبنای «آسیب نرسیدن به سرویس‌های موجود»).

## ۳. دامنه (BLOCKER-F04)

- [ ] مالکیت `hanaso.ir` در Registrar را تأیید کنید.
- [ ] رکورد A برای `preview.hanaso.ir` → IP سرور (+ AAAA اگر IPv6).
- [ ] (پس از آماده‌شدن انتشار) رکورد `hanaso.ir` — تا آن زمان دست نمی‌خورد.

## ۴. تصمیم‌های محصول (گیت‌های OQ — لیبل `owner-decision`)

- [ ] **OQ-013**: تأیید فازبندی MVP (پاسخ عملی زیرساخت داده شد؛ قابلیت‌ها منتظر تأیید صریح‌اند)
- [ ] **OQ-014**: تأیید معماری/Stack (ورودی مستند: ADR-000 + گزارش تجمیعی)
- [ ] **OQ-017**: تأیید تصمیم‌های مدل دیالوگ DD-046..051 · **OQ-016**: سختی گیت mastery (تا M3b)
- [ ] **OQ-020/021**: نقش‌های تحلیل + TTL رویدادها (تا M6) · **OQ-024**: درگاه پرداخت (تا M7)
- [ ] پذیرش تسک‌های در-بازبینی KB (TASK-KB-01..04، DESIGN-03/04، ADMIN-01 — فهرست در `NEXT_ACTIONS` ریپوی KB)

## ۵. اعتبارنامه‌ها (امنیت)

- [ ] جایگزینی PAT فعلی (دسترسی بسیار باز است) با PAT دانه‌ریست با حداقل scope لازم (repo/project/workflow) — Issue باز است.
- [ ] روشن‌کردن راستی‌آزمایی دومرحله‌ای حساب GitHub (اگر نیست).
- [ ] کلید بکاپ آینده (restic) باید **جدا از VPS** ذخیره شود — از M0-10.
