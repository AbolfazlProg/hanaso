## ۲. گیت‌های مستقل

### گیت P1 — پذیرش طرح (ورود از فاز ۱ به فاز ۲)

`gateP1ValidatePlan(plan)` — قواعد: `P1-STRUCT` (کامل‌بودن نقشه)، `P1-SOURCE` (ارجاع منبع همهٔ آیتم‌ها — قرارداد ضد-اختراع)، `P1-MAP` (واگذاری هر آیتم به ایستگاه درست دامنه)، `P1-ORDER` (DAG و ترتیب ۱..N پیوسته — پیش‌نیازها فقط به عقب)، `P1-KANJI` (جایگاه کانجی: ایستگاه اختصاصی، ≥۲ واژهٔ anchor حامل کانجی، آموزش anchor پیش از ایستگاه کانجی)، `P1-BUDGET` (بودجه‌های فریم‌ورک — soft).

CLI: `tsx scripts/lesson-engine/validate-plan.ts <plan.yaml>` · مبدّل فاز ۱ برای فصل‌های موجود: `tsx scripts/lesson-engine/extract-plan-from-chapter.ts <slug> <out.yaml>`

### گیت P2 — آمادگی انتشار (ورود از فاز ۲ به انتشار)

`gateP2PublishReadiness(chapter, {plan, validation, publishPermission})` — قواعد:

- `G2-PLAN` — وفاداریِ فاز ۲ به نقشهٔ پذیرفته‌شده: هر ایستگاهِ نقشه باید در فصل باشد؛ ترتیب/پیش‌نیاز/نوع هم‌خوان؛ ایستگاهِ خارج از نقشه رد؛ جابه‌جایی آیتم به ایستگاه دیگر رد («تغییر پیش‌نیازها توسط ایجنت تولید درس بدون اعتبارسنجی مجدد»).
- `G2-AUTHOR` — تألیف واقعی: هر ایستگاه core با ملاک نمره‌دار باید بلوک نمره‌دار/تعاملی داشته باشد؛ نردبان بازخورد کامل f1/f2/f3 روی همهٔ تمرین‌ها.
- `G2-COMPLETE` — دک کامل: دکِ فقط عنوان/چارچوب (خالی یا فقط scene/wrap-up) رد («صرف داشتن عنوان، واژگان و ساختار اولیه نباید یک ایستگاه را آماده تدریس یا قابل‌انتشار کند»)؛ ایستگاه kanji بدون kanji-card رد؛ ایستگاه واژگانِ core بدون vocab-card رد.
- `G2-VALIDATE` — اعتبارسنجی نهایی: کامپایل (۰ hard) + اعتبارسنج آموزشی (۰ hard) + EQA (۰ خطای بدون-معافیت) — گزارش‌های همان گیت‌های اصلی، بازتولید نمی‌شوند.
- `G2-PUBLISH` — مجوز انتشار صریح مالک؛ هرگز محاسبه نمی‌شود.

CLI: `tsx scripts/lesson-engine/lifecycle-gates.ts <chapterSlug> [plan.yaml]`

## ۳. چرخهٔ حیات محتوا (وضعیت هر فصل/ایستگاه)

```
legacy (فصل‌های موجود قبل از این معماری — سند مرز) → absent → extracted →
planned (P1 سبز) → authored (G2 سبز) → validated (کامپایل+ولیدیتور+EQA سبز) →
publishable (validated + مجوز صریح مالک)
```

هر ایستگاه شش وضعیت جدا دارد (فیلدهای `StationLifecycle`):
`extractionDone` · `prereqsValidated` · `authoringDone` · `blocksComplete` · `finalValidationPassed` · `publishPermission`.

## ۵. مرزها

- فصل‌های موجود بازسازی نمی‌شوند — طرح فصل موجود فقط «سندِ» آن است.
- طرح بدون گیت P1، فاز ۲ را شروع نمی‌کند؛ درفت بدون گیت P2 منتشر نمی‌شود.
- مجوز انتشار همیشه دستی/مالک است؛ گیت‌های ماشینی فقط «آمادگی» را ثابت می‌کنند.
