## ضوابط سخت (ADR-017/DD-074/075)

- ارزیابی مجوز دولایه: Proxy (`/admin/*` layout) + داخل هر Server Action/Handler — backend-enforced.
- **MFA اجباری** همهٔ نقش‌های ادمین؛ نشست ادمین ۱۲س؛ بی‌تحرکی ۳۰دقیقه → خروج؛ re-auth برای عملیات حساس (حذف کاربر/بازپرداخت).
- هر write ادمین + read حساس + تلاش ردشده → `analytics.admin_audit_log` (append-only، hash زنجیره‌ای، reason/diff/result/request_id، نگهداشت ۲۴ ماه؛ ردیف‌ها با حذف کاربر حفظ می‌شوند — GDPR 17(3)).
- فعال‌سازی نقش‌های غیر-owner = سیاست OQ-026 (onboarding/offboarding + بررسی دوره‌ای) قبل از هر استخدام/Agent خودکار.
