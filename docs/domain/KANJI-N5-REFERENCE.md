# مرجع کانجی N5 — HANASO (KANJI-TWO-PHASE §۱)

> تاریخ: ۲۰۲۶-۱۱-۲۲ · مأموریت: مأموریت دوم (زیرساخت بنیادی آموزشی برای کانجی، Memory Station و معماری دومرحله‌ای)
> کد مرجع: `apps/web/src/modules/curriculum/kanji/n5-reference.ts` (GENERATED) + `apps/web/src/modules/curriculum/kanji/index.ts` (lookup layer)

## ۱. جایگاه در معماری

کانجی از این پس بخشی رسمی از معماری آموزشی HANASO است:

- **حقایق کانجی** (خوانش‌ها، معنی، تعداد ضربه، گرید، فراوانی) فقط یک خانهٔ تعریف دارند: ماژول مرجع N5 — همان نقشی که `kana-items.ts` برای کانا دارد.
- **موضعیت تدریس** حقیقتِ جدا و مشتق‌شده است: رجیستری دانش (`knowledge/registry.ts`) هر کانجی را فقط هنگام دیدن یک `kanji-card` در ایستگاه اختصاصی `kanji` ثبت می‌کند (شناسهٔ کانجی یک «مفهوم» رجیستری است — قواعد EQA-1/R5 روی آن حاکم‌اند).
- **هیچ منبع حقیقت موازی ساخته نمی‌شود**: فصل‌ها کانجی را فقط با ارجاع (`kanjiId: 'kj-65e5'`) معرفی می‌کنند؛ داده‌ها هرگز دوباره ننویسی نمی‌شوند.

## ۲. منبع فهرست N5 — صادقانه و مستند

**JLPT فهرست رسمی کانجی منتشر نمی‌کند** (طبق FAQ رسمی، از بازنگری ۲۰۱۰ هیچ فهرست رسمی واژگان/کانجی/گرامری وجود ندارد). این مرجع هرگز خود را «رسمی» معرفی نمی‌کند.

انتخاب ما: برچسب `jlpt=4` در **KANJIDIC2** (پروژهٔ EDRDG) — یعنی فهرست کانجی‌های «سطح ۴» در نظام آزمون چهار-سطحیِ قدیمی که همان مجموعهٔ ۱۰۳ کانجی است که امروز به‌طور رایج «N5» خوانده می‌شود.

| فیلد             | مقدار                                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------- |
| dataset          | KANJIDIC2 (EDRDG)                                                                                       |
| database_version | `2026-326`                                                                                              |
| file_version     | `4`                                                                                                     |
| fetchedAt        | 2026-11-22 (از `edrdg.org/kanjidic/kanjidic2.xml.gz`)                                                   |
| selection        | `misc/jlpt = 4` (نظام قدیمی ≡ مجموعهٔ رایج N5، ۱۰۳ کانجی)                                               |
| license          | CC BY-SA 4.0 (EDRDG licence) — ذکر منبع + ShareAlive                                                    |
| cross-check      | فهرست N5 منتشرشدهٔ practicejlpt.com (۱۰۳ کانجی) — **برابری کامل مجموعه ۱۰۳/۱۰۳** در زمان تولید تأیید شد |

## ۳. دادهٔ ضربه‌ها — KanjiVG

- منبع: **KanjiVG** (CC BY-SA 3.0)، فایل‌های SVG خامِ upstream به‌صورت verbatim در `apps/web/vendor/kanjivg-kanji/<literal>.svg` (۱۰۳ فایل + `README.md` + متن مجوز).
- خروجی تولیدشده: `public/writing-data/<literal>.json` + ردیف در `index.json` — همان قالب centerline-v2 مخصوص کانا (مسیرهای ۱۰۲۴×۱۰۲۴ y-down + medians)؛ سازنده: `scripts/build-kana-writing-data.mjs` (گرامر عمومی مسیر M/c/s/S/C برای کانجی؛ کانا روی پارسر سخت‌گیر قبلی می‌ماند — بازتولید بایت‌پایدار).
- اعتبارسنجی زمان تولید (اسکریپت sandbox؛ در `tests/unit/kanji-reference.test.ts` دائمی شده): تعداد ضربهٔ هر فایل == `stroke_count` کانجی‌دیک؛ ترتیب شناسه‌های ضربه ۱..N؛ هیچ مختصاتی بیرون از فضای کاراکتر.

## ۴. ساختار هر مدخل

```ts
interface KanjiReferenceEntry {
  kanjiId: string; // 'kj-65e5' — شناسهٔ پایدار ASCII = 'kj-' + hex UCS
  literal: string; // نویسه استاندارد
  ucs: string; // کدپوینت یونیکد (hex کوچک — هم‌نام فایل‌های KanjiVG)
  on: string[]; // خوانش‌های ON (کاتاکانا) — عیناً از KANJIDIC2 (≤۳)
  kun: string[]; // خوانش‌های KUN (هیراگانا + نشانه‌های okurigana) — عیناً (≤۴)
  meaningsEn: string[]; // معنی انگلیسی — عین منبع (≤۴)
  meaningFa: string; // معادل فارسی — تألیف HANASO (ترجمهٔ موجز؛ قابل بازبینی، هرگز «رسمی» نیست)
  strokeCount: number; // تعداد ضربه (KANJIDIC2 == KanjiVG)
  grade: number | null; // گرید آموزشی (۱–۶؛ null = خارج از فهرست kyōiku)
  freq: number; // رتبهٔ فراوانی روزنامه‌ای (۰ = بدون رتبه)
}
```

- ترتیب آرایه: گرید آموزشی سپس فراوانی.
- `meaningFa` همان کلاس تألیف واژه‌های مضرب کانا است (DD-011/DD-R05) — بازبینی انسانی آزاد است؛ دادهٔ ساختاری هرگز دست‌نویس نمی‌شود.

## ۵. اتصال به رجیستری دانش و موتور

| مصرف‌کننده                       | قاعده                                                                                                                                       |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Knowledge Registry               | `KnowledgeKind 'kanji'` — ثبت فقط از `kanji-card` در ایستگاه نوع `kanji`؛ پیش‌نیازها = واژه‌های anchor + گلیف‌های خوانش‌ها                  |
| EQA-12 (گیت قرارداد آموزش کانجی) | K1 ایستگاه اختصاصی · K2 اعلام↔تدریس هم‌ارز · K3 واژه‌های anchor پیش از ایستگاه و حامل خود کانجی (≥۲) · K4 بودجهٔ ایستگاه · K5 شناسه در مرجع |
| EQA-8 R4/R5                      | کانجی در سنجش باید با واژهٔ تدریس‌شده پوشیده باشد؛ سنجشِ مستقیمِ شناسهٔ کانجی مشمول قاعدهٔ تدریس-پیش-از-سنجش                                |
| FSRS / Memory Station            | کارت‌های `kj-rec-<id>` (تشخیص) و `kj-wri-<id>` (نوشتن) — قالب‌های جدا در `fsrs/review-contract.ts`؛ ثبت‌نام فقط با تکمیل ایستگاه اختصاصی    |
| Writing engine                   | `writingAvailability('学')` از همان index.json پاسخ می‌دهد — تمرین نوشتن کانجی روی همان زیرساخت کانا                                        |
| رهگیری سطح                       | `kanjiTaughtSequence(registry, chapters)` — کانجی‌های تدریس‌شدهٔ مسیر به‌همراه فصل و سطح، به ترتیب جهانی                                    |

## ۶. ابزارها و بازتولید

```bash
# اعتبارسنجی مرجع (CI): pnpm --filter web exec vitest run tests/unit/kanji-reference.test.ts
# بازتولید writing-data (در pnpm build زنجیر شده):
corepack pnpm --filter web exec node scripts/build-kana-writing-data.mjs
```

تولید اولیهٔ ماژول داده از KANJIDIC2 + KanjiVG با اعتبارسنجی cross-check در زمان تولید انجام شد (۲۰۲۶-۱۱-۲۲)؛ ردیف‌های داده دست‌کاری نمی‌شوند — تغییر مرجع = بازتولید مستند با ثبت نسخهٔ جدید.

## ۷. مرزهای صادقانه

- فصل‌های موجود بازسازی نمی‌شوند؛ هیچ کانجی N5 به‌عجله به درس‌های منتشرشده تزریق نمی‌شود. نمونهٔ تألیف‌شدهٔ فاز ۲ (ایستگاه کانجی 人/国) در `content/lesson-engine/specimens/` فقط اثبات گیت‌هاست، نه محتوای منتشرشده.
- مرجع فقط حقایق نگه می‌دارد؛ «چه کانجی چه وقت تدریس شود» دادهٔ فصل/نقشه است.
