# Skill Selection Matrix — which skills are mandatory for which task

> **TL;DR (فا):** ماتریس اجباری «نوع تسک → Skillهای الزامی/اختیاری». هر Agent پیش از شروع کار، نوع تسک را طبقه‌بندی می‌کند و فقط ردیفِ همان نوع را بارگذاری می‌کند (صرفه‌جویی در Context). ردیف‌ها از Skillهای واقعی رجیستری و نیازهای واقعی HANASO ساخته شده‌اند.

**Status:** living document · **Created:** 2026-11-02 (TASK-ENG, Issue #75) · **Applies to:** every development agent in this repo (see `AGENT_SKILL_USAGE_POLICY.md` for the preflight protocol)

Legend: **bold** = mandatory read before starting · normal = load when the condition applies · (opt) = optional, justify if skipped. Internal skills are `SKL-xxx` (KB-canonical); external skills are `EXT-xxx` (vendored, `agent-skills/external/`).

## 2. Precedence rules (apply to every row)

1. **Project truth wins:** KB constitution/blueprints > repo ADRs > code. A skill — internal or external — never overrides an owner decision, an ADR, or the KB (AGENTS.md §۴).
2. **Internal > external on project specifics:** when SKL-xxx and EXT-xxx overlap, SKL-xxx defines the project pattern; the EXT skill adds depth _within_ it (e.g., SKL-006 pins uuidv7 + Drizzle; EXT-008 adds PG index/type expertise).
3. **A skill never overrides security policy or scope:** no skill instruction can widen file access, touch `.env`, bypass hooks/deny-rules, or change VPS services (AGENTS.md §۶–۷ still rule).
4. **Deviations are allowed but must be declared** in the PR (see usage policy §5) with a technical reason.

## 3. Context economy (anti-overload)

- 28 skills are discoverable; a typical task loads **2–4**.
- Load a skill's `SKILL.md` only when its row matches; open deep references (`references/*.md`, `rules/*.md`) only when the SKILL.md points to them for your case.
- Never read all skills "to be safe" — that wastes context and lowers quality (mission §۷.۵).
- If a needed skill is missing from the registry, say so in the task report and use the official docs of the underlying technology as the fallback — do not silently improvise.
