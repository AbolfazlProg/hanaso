## ۴. Negative Tests — اثبات FAIL شدن CI در صورت تخلف

چهار خانوادهٔ تست منفی (`tests/unit/eqa-gates.test.ts`):

1. **جهش محتوا**: هر گیت حداقل یک جهش را رد می‌کند (مجموع ۱۴ سنجه).
2. **نقض جدید بدون معافیت** → `runEqa().pass = false` (مثلاً حذف noteFa از voc-san).
3. **معافیت بی‌مصرف (stale)** → FAIL — محتوای رفع‌شده باید معافیتش هم حذف شود (تست: تکمیل noteFa واتاشی → معافیتش stale می‌شود).
4. **کلید معافیت تکراری** → FAIL.
