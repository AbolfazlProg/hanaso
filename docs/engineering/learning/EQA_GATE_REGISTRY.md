```bash
pnpm eqa                        # کل گیت‌ها روی فصل‌های بسته‌شده + گزارش فارسی (exit≠0 در خطای بدون معافیت)
```

- **تست مثبت:** فصل واقعی → دقیقاً مجموعهٔ معافیت‌های ثبت‌شده (نه بیشتر، نه کمتر).

- **تست بهداشت معافیت (۴ مورد):** stale / تکراری / نقض جدید / معافیتِ محتوای رفع‌شده — همه باید FAIL شوند.
