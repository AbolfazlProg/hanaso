## §۱ — این فایل چیست؟ (کشف کلیدی، شفاف)

جزوه = متن کامل دورهٔ **«Online Japanese N5 Course» شرکت Attain Corp.** (Udemy، ۲۰۲۲) در ۱۵ درس PDF + ۳ فهرست مرجع (گرامر ۱۱۱ قلم / واژگان ۷۳۲ قلم / عبارات ۷۰ قلم) + راهنمای استفاده. این یافتهٔ KB [01-owner-notes-audit](../../../japanese-learning-kb/docs/knowledge-base/13-educational-methodology/01-owner-notes-audit.md) را تأیید می‌کند: **«روش مالک» در این فایل به‌صورت حاشیه‌نویسی شخصی ثبت نشده؛ آنچه ثبت شده ساختار دورهٔ Attain است که مالک با آن تدریس کرده است.**

**پیامد حقوقی (OQ-029/030/033 — باز):** متن اصلی حق مؤلف Attain دارد؛ در محصول فقط «نقشهٔ محتوایی + انتخاب واژه/گرامر/عبارت به‌عنوان واقعیت آموزشی» استفاده می‌شود (مجاز طبق ممیزی §۲-۲) و **هیچ متن Attain عیناً بازتولید نمی‌شود**. صحنه/شخصیت/مثال/تمرین‌ها اصیل HANASO هستند. این سند خودش فقط اقلام واقعیت آموزشی را نقل می‌کند (واژه/الگوی گرامری/عبارت قراردادی — قابل حفاظت نیستند) نه متن درس.

## §۲ — ساختار هر درس در جزوه (الگوی تکرارشونده)

هر درس = ۷ بخش ثابت: **Ⅰ هدف‌ها (can-do) → Ⅱ مکالمه → Ⅲ واژگان (با کانجی+خوانش+روماجی+انگلیسی) → Ⅳ عبارات → Ⅴ گرامر (توضیح انگلیسی + مثال‌های سه‌گانه) → یادداشت Memo → پیوست (جدول‌های مرجع)**.

این ساختار با مدل **A→D** ی HANASO هم‌خانواده است (DD-045 تأییدشده): مکالمهٔ اول = مواجهه؛ واژگان/عبارات/گرامر = مسیر یادگیری؛ «تماشای دوبارهٔ بدون زیرنویس» = دروازهٔ فهم. انتخاب این جزوه توسط مالک با چشم‌انداز HANASO سازگار است.

## §۳ — درس ۱ «わたしは学生です» — منبع مستقیم فصل Pilot (ممیزی کامل)

### ۳-۱ مکالمه (۱۳ نوبت، ۳ گوینده)

あんどう (ژاپنی) / ワン (دانشجوی چینی) / キム (استاد دانشگاه، کره‌ای — در پایان می‌پیوندد). قوس روایی: سلام متقابل → معرفی کامل آندو (はじめまして + にほんじんです + よろしく) → معرفی کوتاه وَنگ (حذف فاعل) → تأیید + پرسش ملیت (ですね + ですか در یک خط) → پرسش مؤدبانهٔ شخص سوم (あのかた どなた) → معرفی کیم (نام + شغل) → پرسش «کیم هم چینی است؟» → **رد مؤدب با منفی** (いいえ、〜ではありません、かんこくじんです) → واکنش (そうですか。わかりました。) → پیوستن کیم (はじめまして + かんこくからきました + よروشیکو) → یوروشیکوی جمعی.

## §۵ — چه چیزهایی در فصل Pilot مستقیماً از جزوه آمده؟ (خلاصهٔ صادقانه)

1. **انتخاب محتوایی** (کدام ۸ واژه، کدام ۲ خوشهٔ گرامری، کدام ۴ عبارت) = از فهرست‌های واقعی درس ۱.
2. **شکل واژه‌ها** (کانجی + خوانش کانا + روماجی دوبل‌واکه‌ای) = عین فهرست جزوه — پس از اصلاح TASK-LEARNING-02 (قبل از آن わたし/にほんじん/ちゅうごくじん فقط کانا بودند و با ستون کانجیِ جزوه ناهم‌خوان).
3. **قوس مکالمه و توالی آموزشی آن** (سلام → معرفی کامل → معرفی کوتاه → تأیید+پرسش → پرسش مؤدبانه → معرفی سوم‌شخص → بستن) = ساختار مکالمهٔ درس ۱ (بازصحنه‌بندی‌شده با شخصیت‌های HANASO — متن عیناً جدید).
4. **یادداشت‌های کارت واژه** (تشدید کشش واکه در せんせい/ちゅうごく، تجزیهٔ にほん+じん، هشدار さん) = از نکات تلفظی و کاربردی جزوه.
5. **جدول 〜じん/〜ご** (OPT-DEEPDIVE) = الگوی پیوست درس ۱.

## §۷ — نقاط ضعف جزوه (شفاف — از ممیزی KB تأییدشده)

1. **بار نامتناسب:** ۴۰ واژه + ۷ گرامر در «یک» جلسهٔ درس برای زبان‌آموز فارسی‌زبان سنگین است (CLT) → HANASO با قاعدهٔ شکست واحد (S3) درس ۱ را به ۳ واحد می‌شکند (فصل ۱/۲/۳).
2. **فقط انگلیسی:** توضیحات جزوه انگلیسی است؛ HANASO پل فارسی + مقایسهٔ ساختاری (STRUCTURE) را اضافه می‌کند (تحقیق فارسی‌زبانان).
3. **بدون مواجههٔ پیش از آموزش:** جزوه مکالمه را «می‌آموزد»؛ HANASO مکالمه را اول «تجربه» می‌کند (A) و در پایان «می‌سنجد» (D) — completed≠understood.
4. **بدون تمرین بازیابی‌محور:** جزوه تمرین گرامری سنتی دارد؛ HANASO نردبان F1..F3 + بانک mastery ناهم‌پوشان (QUESTION §۴-۵).
5. **روماجی درس‌های ۱-۳:** جزوه برای ناآشنایان کانجی روماجی می‌گذارد؛ HANASO مسیر کانا-اول را با پشتوانهٔ پژوهش انتخاب کرده (فاز ۱ کانا، سپس متن).

## §۹ — جمع‌بندی

جزوه واقعاً خوانده شد (نه خلاصه)، فهرست‌های درس ۱ بایت‌به‌بایت با محتوای فصل تطبیق داده شد، سه اصلاح واقعی محتوایی + یک اصلاح بزرگ رسانه‌ای (صدای واقعی) انجام شد، و همهٔ اقلام جزوه که در فصل ۱ نیامده‌اند با مقصد مشخص (فصل ۲/۳+) در [DIALOGUE_TO_LEARNING_TRACEABILITY](./DIALOGUE_TO_LEARNING_TRACEABILITY.md) ثبت شده‌اند. هیچ محتوای جدیدی به مالک نسبت داده نشده و هیچ قلم مفید جزوه بی‌مقصد حذف نشده است.
