## ۲. نقشهٔ جزیره — قواعد بازنمایی (§۸ معماری)

| قاعده                         | اجرا                                                                            |
| ----------------------------- | ------------------------------------------------------------------------------- |
| هم‌ارزی ساختاری               | هر گره = یک `station_slug` واقعی؛ وضعیت = state واقعی (focus-play fetch از API) |
| خوانایی <۵ ثانیه              | بالا: عنوان+پیشرفت مسیر اصلی؛ وسط: گره بعدی با رنگ شنگرف؛ پایین: دروازهٔ فهم    |
| بی‌ابهام completed/understood | تیک ایستگاه (✓ سبز) ≠ مُهر فهم فصل (理解 سرخ — فقط با گیت)                      |
| بدون استعارهٔ ماجراجویی       | بدون قفل‌کلید/جان/XP؛ قفل واقعی = پیش‌نیاز داده؛ پیشرفت = کسر ایستگاه‌های اصلی  |
| موبایل/RTL                    | تک‌ستون ۳۶۰px؛ ریل عمودی خط‌چین نیلی؛ همهٔ فاصله‌ها logical                     |

**وضعیت‌های بصری گره:** locked (مات + 🔒) · available (حاشیهٔ نیلی) · in_progress (شنگرف + سایهٔ برجسته) · completed/needs_retry (تیک سبز + حاشیهٔ سبز) · اختیاری (چیپ «اختیاری» + جداکنندهٔ بخش «شاخه‌های اختیاری»).

**دروازهٔ فهم:** وقتی مسیر اصلی کامل است، کارت دروازه هم در **بالای** صفحه ظاهر می‌شود (CTA بدون اسکرول) و هم انتهای مسیر. مُهر دایره‌ای 理解 با کنتراست AA.

## ۳. ایستگاه (موتور درس)

- **هدر چسبان:** دکمهٔ «بازگشت به نقشه» (≥44px) + عنوان (با `MixedFaJaText` — ایزوله‌سازی bidi قطعات ژاپنی) + برچسب اختیاری.
- **ریل گام:** سگمنت به‌ازای بلوک + شمارندهٔ «۳ / ۷» (ارقام فارسی) — بدون پرش دستی (جریان خطی آموزشی).
- **یک بلوک در نما:** تمرکز تک‌هدف (S1)؛ دکمهٔ اصلی همیشه یک کار دارد: «ادامه» / «بررسی پاسخ» / «تلاش دوباره».
- **بازخورد درجا:** پنل `role=status` (نه مودال) با آیکن+رنگ+متن (دو-کاناله).
- **عنوان‌های مخلوط:** هر ران ژاپنی در `<bdi dir=ltr lang=ja class=ja-block>` (SKL-003 §۵؛ رفع ایراد bidi ممیزی VLM).

## ۴. تعامل تمرین (L2 — بدون IME)

| شکل                              | اجازه                               | منبع                                              |
| -------------------------------- | ----------------------------------- | ------------------------------------------------- |
| انتخاب (MCQ-۳ / cloze / شنیداری) | کلیک گزینه                          | QUESTION §۲-۳                                     |
| چینش ترتیب                       | کلیک چیپ → جمع شدن در قاب LTR       | Q5/Q13                                            |
| ساخت نیمه‌آزاد                   | چیدن چیپ + **جای نام آزاد** (input) | قالب نیمه‌آزاد L2 (بلوپرینت §۵-۳) — IME کامل = M1 |

نردبان سروری: خطای ۱ → F1 گزاره‌ای · خطای ۲ → F2 سرنخ · خطای ۳ → F3 توضیح + نمایش پاسخ. هیچ جریمه/جشن اغراق‌شده (DD-015؛ فقط «درست!» + تیک).

## ۵. دسترس‌پذیری (SKL-004 §۶ + SKL-002 §۳-۶)

- اهداف لمسی ≥44px (دکمه‌های اصلی 44-56px)؛ فوکوس‌رینگ توکنی؛ landmarks + دکمه‌های aria-label دار.
- `role=radiogroup` برای گزینه‌ها؛ `aria-live=polite` برای بازخورد؛ progressbar با aria-valuenow.
- ارقام فارسی `Intl.NumberFormat('fa-IR')`؛ متن ژاپنی همیشه با `lang=ja` (WCAG 3.1.2).
- `prefers-reduced-motion`: فقط transform/opacity با توکن‌ها (میراث globals).

## ۶. ممیزی بصری VLM (سه‌گذری)

| صفحه                 | قبل                    | بعد | اصلاح اعمال‌شده                                                            |
| -------------------- | ---------------------- | --- | -------------------------------------------------------------------------- |
| نقشهٔ جزیره (دسکتاپ) | ۷٫۵                    | ۸   | حذف آفست مارپیچ (تراز یکنواخت) + جداکنندهٔ اختیاری‌ها + CTA دروازه در بالا |
| ایستگاه گرامر        | ۵٫۵                    | ۷٫۵ | رفع bidi عنوان + هدر چسبان + شمارندهٔ گام + تعادل عمودی                    |
| نقشهٔ موبایل         | ۷٫۵ (FEATURE COMPLETE) | —   | یکنواختی کارت‌ها پذیرفته شد (ریتم آرام Aizen)؛ جداکنندهٔ بخش اضافه شد      |

باقی‌مانده‌های ثب‌تشده (صف اصلاح، S2): تک‌گلیف‌های نادر در فونت جایگزین هدر؛ نوار پیشرفت در حالت ۰/۱۰ نیاز به انیمیشن نرم‌تر دارد.
