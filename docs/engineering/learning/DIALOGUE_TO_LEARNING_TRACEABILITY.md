## ۲. پوشش توکنی (قاعدهٔ توکنی LOAD_SPEC §۲-۴ — گیت مکالمه‌های <۲۰۰ توکن)

| توکن ناآشنا                                                                          | طبقه                | پوشش                                                                                 |
| ------------------------------------------------------------------------------------ | ------------------- | ------------------------------------------------------------------------------------ |
| わたし、〜さん、にほんじん、ちゅうごくじん、だいがく、せんせい、あのかた、イランじん | هسته‌ای (۸)         | VOCAB-1 + مثال‌ها + تمرین                                                            |
| だいがくの せんせい                                                                  | چانک ساختاری «XのY» | گلاس در کارت واژه (の = پیوند نامی — فقط تشخیصی در این فصل؛ تدریس کامل の = فصل بعد) |
| どなた                                                                               | هستهٔ الگوی عبارتی  | کارت EXPRESSION-4 (あのかたは どなたですか)                                          |
| こんにちは、はじめまして、よろしくおねがいします                                     | فرمول               | کارت‌های EXPRESSION                                                                  |
| アリ、ミキ、ソラ、やまだ                                                             | اسم خاص             | گلاس کارت صحنه (معرفی شخصیت‌ها)                                                      |
| はい                                                                                 | چانک پاسخ           | اولین مواجهه در ANCHOR + تمرین GRAMMAR-2 (پاسخ با はい)                              |

**نتیجه:** هیچ توکن ناآشنای طبقه‌بندی‌نشده‌ای وجود ندارد ✓ (اعتبارسنجی خودکار این جدول = تست محتوا).

## ۶. منبع مثال‌های اصیل (استاندارد ۱۵فیلدی — خلاصه)

هر مثال ثبت‌شده در محتوا: نقش (anchor/near/varied/faded) + خط منبع (اگر anchor) + ژاپنی + فارسی + چرا این مثال. تمام مثال‌های این فصل تألیف HANASO هستند؛ دو مثال anchor مستقیماً از مکالمهٔ اصیل همین فصل (L6/L8) نقل می‌شوند. هیچ مثالی از جزوهٔ Attain کپی نشده (OQ-033 مسیر امن).
