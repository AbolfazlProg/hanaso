4. بازطراحی ترکیب استخر practice به ≥۶۰٪ recall-first (EQA-3).
5. تکمیل اسلات‌های §۲-۲ همهٔ کارت‌ها (noteFa واتاشی/دایگاکو + بقیه) و سلسله‌مراتب کارت طبق D-2 (صدا+معنی اول؛ رومی‌جی حذف از نمایش L2).
6. صدای مستقل هر واژه (D-3/DD-119): تولید VOICEVOX پیش‌تولیدشده + mapping پایدار بر اساس شناسهٔ محتوا (نه index کارت) + تست عدم تکرار.

8. اجرای `pnpm eqa` تا صفر خطا/صفر معافیت باقی‌مانده (به‌جز معافیت‌های دارای دلیل مستند جدید).

- **وضعیت دادهٔ امروز (تصحیح TASK-LEARNING-04 §۲):** رکوردهای `poc-user` در production = **فعالیت آزمایشی خودِ مالک** (۶ پاسخ در ۹۰ دقیقه، 2026-11-04) + تست‌های deploy + ممیزی — **هیچ کاربر خارجی/زبان‌آموز واقعیای تا امروز وارد سایت نشده است.** این داده‌ها شاهد «تجربهٔ آزمایشی مالک»اند و مبنای نتیجه‌گیری دربارهٔ رفتار عمومی مبتدیان نیستند.
- **مستندسازی محدودیت:** تا قبل از auth، همهٔ گزارش‌ها باید تصریح کنند پیشرفت زیر حساب مشترک `poc-user` ثبت می‌شود و تفکیک کاربر ممکن نیست (Issue #109 به‌روز شد).
- **زمان‌بندی:** M1 auth — قبل از هر جمع‌آوری دادهٔ ارزیابی کاربران واقعی (EQA-11). **مانع فوری برای بازسازی محتوای فصل اول نیست** — اولویت آن در Roadmap آینده (پس از TL-05..08 یا موازی، طبق تصمیم مالک در M1).
