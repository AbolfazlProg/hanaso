## ۴. تست‌های لازم

1. **Unit:** محتوای Hello در seed (توکن‌ها/روبی/ترجمه) + کامپوننت درس.
2. **Integration (PG18):** seed با Hello → progress کامل A→D برای درس جدید + idempotency باقی سبز.
3. **مرورگر:** رندر درست روبی/RTL در Chromium+Firefox (الگوی آزمون M0-09) + اسکرین‌شات دسکتاپ/موبایل.
4. **دروازه‌ها:** `pnpm verify` (۹ گیت) + format/lint/typecheck.

## ۵. معیارهای پذیرش (AC)

- **AC-901:** درس Hello با روبی درست (FT-002 جزیرهٔ LTR · FT-003 lh≥2) روی Preview با TLS رندر می‌شود.
- **AC-902:** پیشرفت درس در PostgreSQL واقعی ذخیره و در `/learn` دیده می‌شود (استپر A→D زنده).
- **AC-903:** چرخهٔ کامل واحد: دیالوگ ← درس Hello ← تمرین ← ارزیابی → `understood`.
